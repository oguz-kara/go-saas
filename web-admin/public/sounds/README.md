# Notification Sound

Add a notification sound file named `notification.mp3` to this directory.

## Where to Find Free Notification Sounds

1. **Freesound.org** - https://freesound.org
   - Search for "notification" or "alert"
   - Filter by license (CC0 or CC-BY)
   - Download and convert to MP3 if needed

2. **Zapsplat** - https://www.zapsplat.com
   - Free sound effects
   - Search for "notification bell" or "alert"

3. **Mixkit** - https://mixkit.co/free-sound-effects/notification/
   - Free notification sounds
   - No attribution required

## Requirements

- File name: `notification.mp3`
- Format: MP3
- Duration: 0.5 - 2 seconds recommended
- Volume: Normalized to avoid being too loud

## Alternative: Create Your Own

You can create a simple beep sound using online tools like:
- https://www.audiotool.com
- https://soundation.com
- Or use any audio editing software

## If No Sound File

The notification system will work without a sound file. Browser notifications will still appear, but without an audio alert. The application handles missing sound files gracefully.
